# 1. 離職リスクスコアの算出方法

## 組織全体のリスク一覧は「平均」ではなく個別スコア

「組織全体のリスク一覧」タブに並ぶスコアは、**全従業員の平均ではありません**。
1470名それぞれについて、その人自身の特徴量（給与・年齢・満足度・残業有無など）を
モデルに通して**個別に算出**したスコアです（[app.py](../app.py) の `get_scored_employees()`）。

```python
X_all = transform_with_encoders(df, encoders, feature_names)
scores = model.predict_proba(X_all)[:, 1]  # 従業員ごとに個別予測
```

なお、個別詳細カルテの主要リスク要因表にある「平均との比較」列（例：月収 -6%）は別の計算で、
選択中の従業員の値と全従業員の平均値を比較した**表示用の補助情報**であり、
リスクスコア自体の算出には使っていません。

| 項目 | 何の値か | 対象 |
|---|---|---|
| リスクスコア（93.2%など） | この人が離職する確率 | 従業員1人ごと |
| 「平均との比較」バッジ | 選択中の従業員の値 vs 全体平均 | 表示用の補助情報 |

## 離職リスクスコアは「正答率」ではない

似た「%」表示なので混同しやすいが、意味が異なる。

- **離職リスクスコア（例：93.2%）**：その従業員が離職する確率（`predict_proba` の出力）。
  個人ごとの予測値であり、モデルが当たっているかどうかとは無関係。
- **正答率（Accuracy）**：モデル全体の性能評価指標。テストデータ全体で、モデルの予測
  （離職する/しない）が実際の結果と一致した割合。学習時に1回だけ算出する数値で、
  個々の従業員には紐づかない。

| 指標 | 値 | 意味 |
|---|---|---|
| Accuracy（正答率） | 0.840 | モデルの予測が実際の結果と一致した割合 |
| ROC-AUC | 0.798 | モデルの識別性能（ランキングの良さ） |
| Recall（離職クラス） | 0.49 | 実際に離職した人のうち、モデルが正しく検知できた割合 |

つまり「93.2%」は「93.2%当たる」という意味ではなく、
「この従業員が離職する確率が93.2%とモデルが推定した」という意味。
モデル自体の信頼度（正答率）は別途84.0%。

## 確率はどう計算されているか

2段階に分かれる。

### ① 事前準備：モデルの学習（[train_model.py](../src/train_model.py)、過去に1回のみ実施済み）

過去の1470名分のデータ（実際に離職したか＝Yes/No含む）を使って、**LightGBM**
（決定木を大量に組み合わせるアルゴリズム）に「どんな特徴の組み合わせの人が
離職しやすいか」というパターンを学習させる。

```python
model = lgb.LGBMClassifier(
    n_estimators=200,        # 決定木を200本作る
    learning_rate=0.05,
    num_leaves=15,
    class_weight="balanced", # 離職者が少数派なので重み補正
)
model.fit(X_train, y_train)  # 特徴量 → 実際の離職結果 を学習
```

学習中、木ごとに「月収が低い」「残業あり」「満足度が低い」といった条件を組み合わせて
分岐を作り、「この条件に当てはまる人は過去、離職率が高かった」というパターンを
200本分覚える。学習済みモデルは [models/lgbm_model.pkl](../models/lgbm_model.pkl) として
保存され、アプリはこれを読み込んで使う（**アプリ起動のたびに再学習はしない**）。

### ② 実際の予測：確率の算出（アプリ起動のたび・毎回）

```python
risk_proba = model.predict_proba(X_row)[:, 1][0]
```

1. 選択した従業員の特徴量を、学習済みの200本の決定木**全部**に通す
2. 各木が「この人はこの葉（条件分岐の末端）に該当する」と判定し、それぞれスコアを出す
3. 200本分のスコアを合計し、シグモイド関数で0〜1（%表示なら0〜100%）の確率に変換

「93.2%」は、**過去に実際に離職した人たちの特徴パターンに、この従業員の特徴が
どれだけ似ているか**を、200本の決定木の多数決的な仕組みでスコア化した値。

| フェーズ | いつ | 何をする |
|---|---|---|
| 学習 | 事前に1回（train_model.py実行時） | 過去データから「離職しやすい特徴パターン」を200本の決定木に学習 |
| 予測 | アプリで従業員を選ぶたび | その人の特徴量を学習済みの木に通し、確率に変換 |
